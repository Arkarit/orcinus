== Introduction to Orcinus

Orcinus is a file manager for power users, based on Dolphin.
It keeps what Dolphin does and adds to it.

This handbook contains Dolphin's handbook.
Where Orcinus works differently or offers more, the Orcinus chapters say so.
Dolphin's chapters start with xref:introduction[].
