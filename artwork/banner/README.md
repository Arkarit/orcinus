# Orcinus banner

The parts of the banner (`website/images/banner.jpg`, 1719 × 557 pixels), so it can be rebuilt or
changed without the original image editor file:

- `OrcinusBackground.png`: the background, AI-generated, CC0-1.0, 1772 × 768 pixels. The banner
  uses a flatter crop of it.
- `BowlbyOneSC-Regular.ttf`: the font of all text, Bowlby One SC by Vernon Adams, SIL Open Font
  License 1.1 (`OFL.txt`).
- The Orcinus icon (`src/icons/org.kde.dolphin.svg`), top left, with "ORCINUS" below it.

The text is white with a dark drop shadow: "A Dolphin." bottom left, "Just a big one." bottom
right. The tagline stays English in every language.

Export as JPEG (quality about 85, metadata stripped) to `website/images/banner.jpg`.
