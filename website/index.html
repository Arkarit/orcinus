What is Orcinus?

Orcinus is the scientific genus name of the orca – the largest living member of the dolphin family. And that's exactly why we chose it.

Orcinus is a fork of Dolphin, KDE's well-established file manager. While Dolphin is designed as a versatile file manager for a broad range of users, Orcinus is aimed particularly at power users who place high demands on functionality, configurability, and extensibility.

We follow a simple guiding principle:

Make the common case simple and excellent.
Make the uncommon case possible.

Frequently used features should be simple, intuitive, and exceptionally well implemented. More specialized requirements should face as few artificial limitations as possible.

What does Orcinus offer?

Orcinus builds directly on Dolphin. Its proven architecture, integration with KDE Plasma, and familiar user experience remain intact. If you're familiar with Dolphin, you'll feel right at home with Orcinus.

The differences lie in numerous extensions and improvements – ranging from small but meaningful everyday refinements to substantial new features.

The goal isn't to cram in as many features as possible. We want to create a file manager that remains practical, well-organized, and enjoyable to use, even for demanding tasks.

Improvements include

  • A toolbar and a location bar for every view. Each half of a split view has its own Back, Forward, view mode and location.
  • Better split views. Each view keeps its own display style; views can be linked to follow the same folder and selection, and moved to a tab or a window of their own.
  • Profiles. Switch the whole look of a window – views, toolbars, panels, status bar – with one click or shortcut.
  • A built-in image and video viewer. Full screen, fast, and coupled to the view: press Esc and the picture you were looking at is selected.
  • Cushion Treemap. See at a glance what takes up the space below a folder, and clean it up right there.
  • Show flat. The files of all subfolders in one list.
  • Expandable folders in the Compact view, with colored backgrounds and folder names that show where each folder's contents start and end.
  • File name highlighting by rules: executables, links, file types, name patterns.
  • Smaller things that add up: a filter that keeps its text and leaves folders alone, scripts that run in a terminal, dragging from anywhere in a Details row, and more.

For a detailed overview of the changes, please see Orcinus compared to Dolphin and the changelog.

Install

Orcinus installs next to Dolphin and leaves it untouched: own program, own settings, own menu entry. Dolphin's version control plugins and service menus are used when they are installed.

Ubuntu 26.04 and 26.10

sudo add-apt-repository ppa:arkarit/orcinus
sudo apt install orcinus

Arch Linux

From the AUR: orcinus for the release, orcinus-git for the development version.

yay -S orcinus

Other distributions

Build from source: see the README. Orcinus needs Qt 6 and KDE Frameworks 6.23 or newer.

Development and Roadmap

Orcinus is intended to remain closely connected to Dolphin in the long term.

The Orcinus repository is based directly on the Dolphin repository. Changes and improvements from Dolphin's ongoing development will be regularly incorporated. This allows Orcinus to continue benefiting from its proven foundation while we pursue our own ideas and features.

And we have quite a few of those in mind.

Our plans range from small improvements that eliminate everyday annoyances – such as automatically handling unwanted executable permissions when copying files from NTFS to Linux file systems – to much larger extensions.

One long-term focus is the integration of artificial intelligence. Beyond file management, Orcinus is intended to eventually assist with everyday tasks, as well as operating system configuration, maintenance, and troubleshooting.

As always, new features should solve real problems and integrate naturally into the user experience.

Contributing

Orcinus is developed entirely with the assistance of artificial intelligence. Contributions created partly or entirely using AI are therefore explicitly welcome.

What matters is not how a contribution was created, but what it delivers.

Of course, AI-generated pull requests are subject to the same careful review as any other contribution. Functionality, code quality, and proper integration into the existing project are what count.

If you prefer to write your code by hand, you're naturally just as welcome.

We welcome good ideas, suggestions for improvements, bug reports, and contributions to the continued development of Orcinus: see the issue tracker and the contributing guide.
