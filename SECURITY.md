# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues. Use GitHub's private
vulnerability reporting instead: on the
[Security tab](https://github.com/Arkarit/orcinus/security) choose
"Report a vulnerability".

If the problem also exists in an unmodified Dolphin or in KDE Frameworks, it
belongs to KDE as well; see
[KDE's security policy](https://kde.org/info/security/) (security@kde.org).

## Supported versions

Only the latest release of Orcinus receives security fixes.
